갤럭시 모드 및 루틴 설정 가이드

📱 갤럭시 '모드 및 루틴' 1분 연동법

삼성 갤럭시 스마트폰의 기본 앱인 [모드 및 루틴]을 사용하면, 아침에 알람을 끄자마자 본 웹앱이 자동으로 팝업되고, 학교 도착 시 일정표가 자동 발송됩니다.

1
루틴 #1: 아침 알람 끄면 버스 시간 보기
[모드 및 루틴] → [+] 추가 → 언제 실행할까요: [알람 해제될 때] 선택 (등교 알람 지정) → 무엇을 할까요: [웹사이트 열기] 선택 후 아래 URL 붙여넣기
2
루틴 #2: 학교 정류장 하차 시 일정표 보기
[모드 및 루틴] → [+] 추가 → 언제 실행할까요: [장소: 학교 정류장 도착 시] 또는 [학교 Wi-Fi 연결 시] → 무엇을 할까요: [웹사이트 열기] 선택 후 아래 URL 붙여넣기

🔑 공공데이터포털 API 키 연동

발급받으신 인천광역시 버스도착정보 일반 인증키(Encoding/Decoding)를 입력하시면 즉시 실시간 인천 BIS와 직접 통신합니다. (키가 없으면 스마트 모의 데이터셋이 동작합니다)

📲 갤럭시 홈 화면에 앱으로 추가하기

삼성 인터넷 또는 크롬 브라우저 오른쪽 상단 [⋮] 메뉴 → [홈 화면에 추가]를 누르시면 상단 주소창 없는 100% 네이티브 갤럭시 앱처럼 동작합니다.
